# Apelle 11: Moon Landing Condition Visualizer
NASA Space App Challenge by the Just Happy Accidents team.

## How to use
### Installation
This project requires Node.js to run

- Run `npm install` in the root directory
- Run `npm run dev` to run locally

Or go to https://martinetto33.github.io/moon-sack-jha/ to run the project.

### Format for uploading landing sites
If you wish to add a landing site, you can do so by uploading a file in the .geojason format. You can look at an example in /public/sites/landing-sites-A3.geojason.

## Project Summary
Apelle 11 presents itself as a 3D visualization of the Moon, the Sun and Earth. It allows the user to pick a date, a landing site (either by loading it in or by selecting one of the potential future Artemis III landing sites, which are available by default) and a set of conditions they wish to see met on their mission date. The user is then shown the highlighted area of the landing site on the Moon, technical information about the environmental conditions and the date of the closest match to their desired conditions in a three month interval. The user can view the Moon in first person to check for irregularities in the ground, and focus on the Sun and the Earth as they can be seen from the Moon's surface.

Apelle 11 addresses the challenge by combining the provided resources into one easy way to check all the relevant information of a landing site; it is important for regular citizens to have access to professional tools, and it is important for professional tools to be quick and easy to use, to help the productivity of experts around the world.
